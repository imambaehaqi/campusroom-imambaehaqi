# Sistem Peminjaman Ruang Universitas

Aplikasi manajemen peminjaman ruang universitas dengan role Admin & Dosen.

## Tech Stack
- Backend: NestJS + Prisma + PostgreSQL
- Frontend: React (Vite) + TailwindCSS + Zustand
- Auth: JWT (Passport)
- Testing: Jest (backend) + Vitest (frontend)

## Fitur
- [ ] Authentication & Role-based Access (Admin, Dosen)
- [ ] CRUD Ruang + Sinkronisasi Webservice
- [ ] CRUD Pengajuan Peminjaman + Approval
- [ ] Validasi anti-bentrok jadwal
- [ ] Dashboard ringkasan
- [ ] Pencarian & filter
- [ ] Automated testing
